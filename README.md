# Web Canvas

브라우저에서 바로 쓰는 그리기 캔버스. Course(AI 설계 캔버스)의 캔버스 부분만 떼어 낸 독립 프로젝트입니다.

- 도형·글자·선/화살표·선택/이동·확대축소·되돌리기
- 심플 모드 (설정 → 심플 모드): 오른쪽 위 버튼을 설정 하나만 남김
- 저장: 로그인 없이 이 브라우저에만 (캔버스 localStorage, 라이브러리 IndexedDB) · 파일로 저장/불러오기
- 서버·DB·외부 서비스 없음

## 실행

```
npm install
npm run dev
```
